Configuración SMTP
Estado actual del servidor de emails.
No verificado
Configuración en .env:
SMTP_HOST — servidor SMTP (smtp.gmail.com para Gmail)
SMTP_PORT — puerto (587 para TLS, 465 para SSL)
SMTP_USER — tu email
SMTP_PASS — contraseña o App Password de Gmail
FROM_NAME — nombre que ven los alumnos como remitente

Para Gmail: Activá verificación en 2 pasos → Contraseñas de aplicación → creá una de 16 caracteres y usala como SMTP_PASS.

Alternativa gratuita — Brevo: brevo.com → gratis hasta 300 emails/día. Ideal para empezar.

Guía de deploy
Railway (recomendado)
1. Subí los archivos a un repo en GitHub
2. railway.app → New Project → Deploy from GitHub
3. Variables de entorno: MP_ACCESS_TOKEN, ANTHROPIC_API_KEY, SMTP_USER, SMTP_PASS, ADMIN_PASSWORD, JWT_SECRET, BASE_URL=https://tu-app.up.railway.app
4. Deploy automático en 2 minutos.

Webhook Mercado Pago
mercadopago.com.ar/developers → Webhooks → https://tu-app.up.railway.app/api/webhook → evento: payment
